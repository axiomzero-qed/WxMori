What it does

把本地记录，变成可用的工具

按需探索与导出。实际可用范围取决于本地微信数据、配置和当前版本能力。

⌕

查找会话与消息

按关键词列出会话、联系人和匹配消息，支持日期范围与分页。

↗

按需导出

将选定会话按月导出为 TXT 或 JSONL；也可批量导出并查看文件清单与 SHA-256。

⌘

接入本地 MCP

通过标准 stdio MCP 接口，供支持 MCP 的 AI 宿主调用；也可只用命令行。

◉

检查数据状态

查看本地账号目录、配置和密钥环元数据。身份检查依据匹配信息，不靠昵称猜测。

▤

读取聊天数据库

面向微信 4.x 本地数据库；读取使用临时副本，不修改源数据。

⌁

实验性密钥捕获

仅 Windows x64（Intel / AMD） 支持登录时实验性自动捕获，且当前版本的真实捕获尚未实测。

Get started

三步开始

先下载对应系统压缩包。以下以 Windows 解压后的终端命令为例。

01 / 下载

下载并解压

选择下方对应系统的 ZIP。Windows 可在解压目录打开 PowerShell，或将程序目录加入 PATH。

02 / 初始化

创建本地配置

.\wxmori.exe init --data-dir <db_storage>

此命令创建配置文件，不会打开数据库。加密数据库需按文档准备可用密钥，才能读取内容。

03 / 使用

连接宿主或查看文档

.\wxmori.exe serve

在 MCP 宿主中配置 wxmori.exe 的完整路径与 serve 参数。压缩包内附完整中英说明；也可参阅 MCP 配置说明 ↗。

FAQ

常见问题

WxMori 会把聊天内容上传到哪里吗？

WxMori 是本地程序，读取和导出由本机执行。若你把 MCP 连接到 AI 宿主并让模型读取或总结内容，发送给模型的内容由该宿主及其连接的模型服务处理；请查看它们各自的数据政策。

Windows 会自动捕获密钥吗？

登录时自动捕获仅支持 Windows x64（Intel / AMD），仍属实验功能。真实捕获仅在 alpha1 的单账号样本中验证；alpha2 尚无新的真实捕获实测。启动捕获不代表成功，请阅读安全说明。

这是微信官方软件吗？

不是。WxMori 是独立开源项目，与微信及其运营方无隶属或背书关系。

alpha 预览版适合日常使用吗？

当前仍是 alpha 预览版，功能、兼容性和捕获行为可能变化。请先备份重要数据，并阅读发布说明与已知验证范围。

支持所有微信版本和平台吗？

项目面向微信 4.x 本地数据库；实验性登录捕获目前仅限 Windows x64（Intel / AMD）。其他平台上的 CLI/MCP 可用性以发布包与文档为准，不代表支持自动捕获。

如何确认下载文件未损坏？

复制下载区显示的 SHA-256，与本地计算出的文件哈希比较；也可在 GitHub Releases 查看原始发布信息。
