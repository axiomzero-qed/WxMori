What it does

Turn local records into something useful

Explore and export on demand. Availability depends on local WeChat data, configuration, and release.

⌕

Find chats and messages

List sessions, contacts, and matching messages with keyword, date-range, and paging support.

↗

Export on demand

Export selected chats by month as TXT or JSONL, or batch export with a manifest and SHA-256 hashes.

⌘

Connect through local MCP

Standard stdio MCP interface for compatible AI hosts. You can also use the CLI on its own.

◉

Inspect data status

Review local account directories, configuration, and keyring metadata. Identity checks rely on matching data, not guessed names.

▤

Read chat databases

Designed for local WeChat 4.x databases; reads use private temporary copies without changing source data.

⌁

Experimental key capture

Experimental login-time capture is limited to Windows x64 (Intel / AMD). Alpha2 has no new real-capture trial.

Get started

Three steps to get going

Download the archive for your system. These terminal examples use Windows after extraction.

01 / Download

Download and extract

Choose your system's ZIP below. On Windows, open PowerShell in the extracted folder or add the program directory to PATH.

02 / Initialize

Create a local config

.\wxmori.exe init --data-dir <db_storage>

This command creates a config file; it does not open databases. Encrypted databases need a usable key prepared as described in the docs before they can be read.

03 / Use

Connect a host or read the docs

.\wxmori.exe serve

Configure the full path to wxmori.exe and the serve argument in your MCP host. Full bilingual documentation is included in the archive. See the MCP setup guide ↗.

FAQ

Frequently asked questions

Where does WxMori send my chat content?

WxMori is a local program; reads and exports run on your device. If you connect MCP to an AI host and ask a model to read or summarize content, the host and its connected model service handle the content sent to the model. Review their data policies.

Does Windows capture keys automatically?

Login-time capture is experimental and only supported on Windows x64 (Intel / AMD). Real capture was verified only on a single-account alpha1 sample; alpha2 has no new real-capture trial. Starting capture does not mean it succeeded. Read the security notes first.

Is this official WeChat software?

No. WxMori is an independent open-source project and is not affiliated with or endorsed by WeChat or its operator.

Is the alpha preview ready for daily use?

This is still an alpha preview. Features, compatibility, and capture behavior may change. Back up important data and review release notes and tested scope.

Does it support every WeChat version and platform?

The project targets local WeChat 4.x databases; experimental login-time capture is limited to Windows x64 (Intel / AMD). CLI/MCP availability elsewhere depends on release archives and docs and does not imply automatic capture.

How can I verify a downloaded file?

Copy the SHA-256 shown in the download list and compare it with a locally calculated file hash. GitHub Releases also has the original release information.
