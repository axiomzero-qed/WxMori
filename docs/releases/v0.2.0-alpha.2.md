# v0.2.0-alpha.2 Preview Notes / 预览版说明

**Status / 状态:** Preview release dated 2026-10-18. Release archives are generated separately by the release workflow. / 预览版，日期为 2026-10-18。发布压缩包由独立的发布工作流生成。

## Changes / 更新内容

**中文：** 新增本地账号目录元数据清单和密钥环元数据查看；`init` 仅做元数据检查与配置写入，配置目标已存在时返回 `CONFIG_EXISTS`，显式 `--force` 才原子替换。新增 `whoami`/状态检查身份、稀疏本地历史诊断、全会话分文件导出、九工具 MCP 接口，以及捕获错配诊断和更清楚的进度输出。只有经所选数据库 HMAC 验证的密钥才可保存；仅当其他本地账号两个核心数据库首页在不同盐下通过 HMAC，且所选账号连续 10 秒没有有效匹配时，才报告 `KEY_ACCOUNT_MISMATCH`。候选 AES 验证失败本身不代表账号错配。

**English:** Adds local account-directory and protected-keyring metadata listings; `init` performs metadata checks and config writing only, returns `CONFIG_EXISTS` for an existing target, and atomically replaces it only with explicit `--force`. Also adds `whoami`/status identity inspection, sparse-local-history diagnostics, separate per-session exports, a nine-tool MCP interface, and clearer capture mismatch/progress reporting. Only keys HMAC-verified against the selected database may be saved. `KEY_ACCOUNT_MISMATCH` requires HMAC-valid first pages from two core databases in another local account under distinct salts, while the selected account has no valid match for 10 seconds; failed AES-candidate checks alone do not indicate a mismatch.
